Self-critique before build: a numbered project gallery, archive and Lab would create false volume. Removed. No terminal frame, glowing panels or filler metadata. The approved near-black palette is intentional user direction, not an unexplained default. Shell cues name real navigation actions. Source-map interactivity explains actual mode differences; it does not simulate execution. Contact cannot claim direct messaging until a real email is supplied.
